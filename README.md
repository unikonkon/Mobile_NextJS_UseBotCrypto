# Mobile_NextJS_UseBotCrypto 

ต้องการลง Tech Stack ที่เกี่ยวกับ การทำงาน  เปิด bot ระบบวิเคราะห์สัญญาณซื้อขายเหรียญคริปโต พร้อม Backtest และ Live Trading ผ่าน Binance API

Framework	Next.js ล่าสุด  มี State Managemen มี PWA เป็นตัวสร้างเพิ่อทำเป็น web ใช้ในมือถือ หรืออื่นๆๆถ้าดีกว่าแนะนำมา

ใช้ 1. GET /api/klines — ดึง Candlestick Data  ดึงข้อมูลแท่งเทียนจาก Binance @README.md  และต้องมีกราฟ tradingview มาคำนวณ สัญญาญ ซื้อขาย จากใน
